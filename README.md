# Gridmate — Space-themed Tic Tac Toe

A responsive two-player Tic Tac Toe website built with HTML, CSS, and vanilla JavaScript. No framework or build step is required.

## Features

- Animated splash intro with a skip button.
- Cosmic starfield and blue / warm-yellow visual palette.
- Typewriter hero heading and slowly rotating Tic Tac Toe artwork.
- Responsive 3×3 two-player board.
- Win detection for rows, columns, and diagonals; draw detection; winning cells highlighted.
- Victory / draw popup with next-round controls and win confetti.
- Scoreboard for Player X, Player O, and draws.
- Optional synthesized sound effects (off by default) and a strategy hint button.
- Move counter, progress bar, and animated move feedback.
- Designed rule cards with scroll-reveal effects.
- Keyboard focus styles, an accessible live turn status, modal keyboard dismissal, and reduced-motion support.

## Run locally

1. Download / extract this folder.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Click squares to play; use **Strategy hint** for a nudge and **Sound off** to opt into sound effects.

## Publish with GitHub Pages

1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, and save.

GitHub Pages publishes the site at `https://github.com/krunal2008-ctrl/Tic-Tac-Toe-Game/` after deployment completes.

## Files

- `index.html` — page structure, intro, game, rules, and result modal.
- `style.css` — cosmic background, blue/yellow theme, layout, responsive styles, and animations.
- `script.js` — game logic, sound, hints, result modal, confetti, and page animations.
- `screenshots/` — refreshed desktop/mobile previews, result-popup preview, and animated gameplay demo.
